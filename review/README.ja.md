# カタログの操作

Windowsは `open_review.cmd`、Macは `open_review.command`、Linuxは `sh ./open_review.sh` でカタログを開きます。[OS別の起動](../docs/PLATFORMS.md)も参照してください。初期ポートは8790です。キャラクター・スタイルを切り替え、名前や作品・元タグで絞れます。Copyright順は現在の条件に該当する件数の降順です。

検索条件、表示設定、ページはブラウザーに保存します。非表示・お気に入り・星評価は `outputs/review_state.json` に保存します。リロード・再起動しても保存済みの内容を維持します。

画像をクリックすると拡大し、Krea2用プロンプトと元タグをコピーできます。「非表示」は画像ファイルを消しません。Undoは直前の非表示操作をまとめて戻します。「非表示一覧」「再表示」でも戻せます。物理削除済みの不合格画像は戻せません。

表示中の画像をまとめて選んで非表示にできます。「非表示を除く一覧を保存（CSV）」は現在のタブの一覧、「非表示の一覧を保存（TXT）」は非表示分の一覧を保存します。確認画面を終了するボタンは削除済みです。

## 画像の追加・編集

1. カタログ上部の「画像を追加」または `open_editor.cmd` を開く。
2. WebP・PNG・JPEGを選ぶかドロップする。
3. 必要な項目だけ入力し「登録」を押す。すべての文字欄を空欄にしても登録できます。

空欄の名前は画像のファイル名、作品は「未分類」です。元画像はコピーし、再圧縮しません。読み取れるメタデータがあれば空欄だけに補助入力します。入力内容を消した場合は空欄のまま保存します。

「CSV・保存JSON（任意）」では元タグCSV・スタイルCSV・生成用サンプルCSV、または自分のCSVから1行を選んで入力できます。未知の列は対応を選べます。CSVを選んだだけでは登録されません。JSONがない画像も登録でき、壊れたJSONは「JSONを外す」で外せます。

同じ画像が既にある場合は確認を表示します。「別項目として追加」を選んだ場合だけ重複を保存します。登録後の「カタログで確認」から新しいカードを開けます。

画像をクリックして開く情報パネルの「編集」で、同じパネル内の名前・作品・プロンプト・タグを変更できます。下の右にある緑の「変更を保存」で確定します。左のオレンジの「キャンセル（変更を破棄）」は未保存の変更を消し、元の情報表示へ戻します。右上の青い「閉じる（入力を残す）」とEscは下書きを残してパネルを閉じます。同じ画像を再び開くと続きから編集できます。種類の変更は独立したEditorで行えます。編集は変更された項目だけに適用し、画像・生成記録・非表示・お気に入り・星評価を保持します。「元画像を開く」「画像の場所を開く」、存在する場合の「保存JSONを開く」も利用できます。画像の場所を開く操作はWindows Explorerでファイルを選択します。

## ツールの目的と終了操作

Editorは、自分で生成したキャラクター／スタイル画像を追加し、名前・作品・再利用文・タグを整えるためのツールです。画像を生成する機能や自動の合否判定ではありません。

右上の「閉じる（入力を残す）」またはEscは、入力途中の画像・文章・添付JSONをブラウザーの下書きとして残して終了します。次にEditorを開くと続きを入力できます。ブラウザーがタブを閉じられない場合はカタログへ戻ります。下書きは同じブラウザー・同じカタログURLで使い、カタログへの登録とは区別します。

下の「キャンセル（入力を破棄）」は未確定の入力と下書きを消して終了します。保存済みカードは変更しません。「入力欄を空にする」は文字欄だけを空にし、そのまま編集を続ける操作です。

カタログへ確定する操作は、追加時の「登録」、既存項目の編集時の「変更を保存」です。言語・テーマはカタログから引き継ぎ、Editorでは切替を置きません。入力欄と画像の左右配置はカタログの拡大画面に合わせています。

入力途中の文字はブラウザーに随時保存します。ブラウザー自体の閉じるボタンやF5では画像の選び直しが必要な場合があるため、画像ごと残すにはEditorの「閉じる」を使ってください。追加済みデータは `outputs/user_catalog.json` と `outputs/user_items/`、修正は `outputs/user_catalog_edits.json` です。バックアップ・PC移行時はこの3つと `review_state.json` を含むカタログをコピーします。

## PythonとWindows起動

起動処理はカタログとEditorで共通です。Python 3.10以上、Pillow 10以上13未満とWebP対応を確認し、利用できる既存Pythonを優先します。足りない場合は検出したPythonから `.venv` を作り、専用環境にPillowを導入します。初回の導入にはインターネット接続が必要です。Python本体が見つからなければ選択・導入案内を表示します。Python本体は同梱していません。

特定のPythonを利用する場合は `KREA2_CATALOG_PYTHON` 環境変数か、次の引数で指定できます。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/open_review.ps1 -Python "C:\Python\python.exe"
```

同じカタログの起動済みサービスは再利用します。他のサービスが8790を使っている場合は空きポートを選び、実際のURLを開きます。起動済みの別サービスを停止・置換しません。起動失敗時は `outputs/review_server.err.log` を確認してください。

手動で起動する場合はPillowのあるPythonから `python -B review/server.py --root . --port 8790` を実行し、終了はCtrl+Cです。ランチャーによる起動はバックグラウンドで動き、ブラウザーを閉じても登録内容は残ります。

画像の場所、再生成用JSONの別保管、配布時の注意は [README](../README.md) を参照してください。
