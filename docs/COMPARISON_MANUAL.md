# Set up AnimaDex comparison without a skill

[日本語の手順](#日本語の手順)

The catalog works on its own. AnimaDex comparison is an optional, separate tool. You do not need Codex or an installed skill to follow these steps.

## Before using optional AnimaDex comparison

AnimaDex is a separate application: [website](https://animadex.net/), [local application and installation instructions](https://github.com/zetaneko/AnimaDex), [official dataset import guide](https://github.com/zetaneko/AnimaDex/blob/main/docs/import-from-site.md).

1. Install/configure AnimaDex using its own instructions. Start it once and confirm its local catalog opens correctly.
2. Import/download the character metadata and reference thumbnails to your PC. The starter samples are not the full reference collection. Follow AnimaDex's current offline dataset export/import procedure; download the images needed for your comparisons, and confirm they display locally. Merely opening the website does not download a local reference library.
3. Open this catalog's `AnimaDex-Comparison/START_COMPARISON` file and select that AnimaDex installation. If its DB/images use a custom data directory, select them under Advanced settings.

**AnimaDex does not need to remain running.** This tool reads its local SQLite database read-only and serves local reference images directly; it does not call AnimaDex's web server. Keep the downloaded DB and image files in place. Creating/rebuilding pairs and applying decisions require the selected Krea2 catalog to be running. Viewing an already prepared comparison does not require either application's main server.

If installation is confusing, you can ask an LLM assistant such as ChatGPT, Claude, or Codex to help set up AnimaDex using its official instructions. For example: “Help me install AnimaDex on my OS, import its character metadata and thumbnails locally, and confirm the local gallery works before configuring Krea2 comparison.” Tell it your OS and chosen folders; keep export tokens and other credentials private. This catalog does not install AnimaDex automatically.

## First setup — choose folders on screen

1. Extract the complete ZIP. Open `AnimaDex-Comparison` beside the main START_HERE file.
2. Open `START_COMPARISON` with your OS in its name. A setup page opens. The catalog folder is already filled in for the bundled version.
3. Click **Choose folder…** beside AnimaDex and select its local installation using the on-screen folder chooser. The database and reference-image folder are detected from it.
4. If the catalog is stopped, click **Start catalog**. It starts only the selected catalog and leaves other services alone.
5. Choose all characters or a copyright/work. Click **Check connection** to display available pairs and missing/ambiguous references.
6. Click **Save settings and open comparison**. No commands, JSON editing, or AI assistant are needed. Settings are saved only after the comparison has successfully started.

If detection fails, expand **Advanced settings** to select the database file or reference-image folder. You can also choose a parent folder for comparison data. Existing comparisons and verdicts are preserved; a new review folder is created when reconfiguring.

The comparison HTML, JavaScript and CSS templates are bundled under `AnimaDex-Comparison/app/templates`. They do not need to be generated by an assistant. The template needs the local server to serve configured images; opening an unconfigured HTML file directly is not the startup method.

The folder chooser is part of the HTML setup screen. Select a drive or Home, open folders, and click Select this folder. It uses the same UI on all OSes and does not require Tk, terminal input, or browser filesystem permissions. Cancel leaves the previous folder unchanged.

## Every subsequent use

Open the same **START_COMPARISON** file again. It reuses the comparison server if already running. You do not need to find an HTML file or enter setup commands again. Keep the whole comparison folder together, including its `app` folder.

To end the background process, click **Stop server / サーバー停止** in the comparison page. Your browser tab stays open. Closing only the browser tab leaves the server available for reopening.

Routine comparison display uses the prepared local images; it does not require the catalog server or AnimaDex browser page to remain running. Applying decisions requires the catalog to be running again.

## Save and apply selected decisions

Choose match, mismatch, or hold; check the decisions you want to confirm, then export the selected confirmed JSON. Exporting does **not** modify the catalog.

For manual application, start the catalog and use the following commands from its extracted folder. Replace the three placeholders with the actual paths. The settings file was created for you inside the comparison folder's `app` folder.

```sh
python app/skills/krea2-animadex-review/scripts/review.py apply --config "<comparison-folder>/app/settings.json" --review-dir "<comparison-folder>" --decisions "<exported-decisions.json>" --dry-run
```

Check the reported changes, then repeat the same command without `--dry-run` to apply them. Only selected, confirmed match/mismatch choices are applied. Unselected choices, hold, unrelated favorites/ratings, and image files remain unchanged. Images are hidden/restored rather than physically deleted.

## If setup cannot finish

- **Catalog not running:** Open its START_HERE file first, then rerun setup.
- **Folder already exists:** Open that folder's START_COMPARISON file. To create a different comparison, choose a new folder; existing choices are not overwritten.
- **No unique database or thumbnails:** Confirm the local AnimaDex installation. Nonstandard database layouts may require explicit configuration using the advanced [comparison reference](COMPARISON_SKILL.md).
- **Python missing or too old:** Install Python 3.10+ from the official links in [platform setup](PLATFORMS.md), then reopen the same startup file.
- **Saved port occupied:** Do not kill an unrelated program. Check its owner or ask an assistant to repair the comparison setup.
- **Images or installation moved to another PC/OS:** Export existing decisions first, then prepare a new comparison with the new local paths. Do not assume saved absolute image paths work on another OS.

Real AnimaDex installations and physical macOS/Linux desktop operations are not established by synthetic tests. See the current release's actual verification results.

## 日本語の手順

1. ZIPをすべて展開し、カタログの起動ファイルと並ぶ `AnimaDex-Comparison` フォルダーを開きます。
2. 自分のOS用の **START_COMPARISON** を開きます。未設定の場合は初期設定画面が開きます。
3. AnimaDex欄の **「選択…」** を押し、画面内のフォルダー選択でローカルのAnimaDexを選びます。同梱版ではカタログの場所は入力済みです。
4. カタログが停止していれば **「カタログを起動」** を押します。
5. 全キャラクターまたは作品を指定し、 **「接続を確認」** で比較可能件数と参照なし件数を確認します。
6. **「設定を保存して比較を開く」** を押します。コマンド入力・JSON編集・スキル導入は不要です。

次回も同じSTART_COMPARISONを開くと比較画面へ進みます。比較画面の **「比較設定」** で設定画面へ戻れます。再設定では以前の比較と判定を保持し、新しい比較データを作ります。設定画面の **「変更を取り消す」** は今回の未保存の入力を破棄します。

自動検出できない場合だけ「詳細設定」でDBファイル・参照画像フォルダーを個別に選びます。選択画面でドライブまたはHomeからフォルダーを開き、「このフォルダーを選択」を押します。Tkの追加やパス入力は不要です。「キャンセル」では以前の選択を変更しません。

設定サーバー・比較サーバー・カタログは別の処理です。それぞれの画面の停止ボタンで終了します。ブラウザーを閉じるだけではバックグラウンド処理は停止しません。

判定の反映は上記「Save and apply selected decisions」の手順です。選択・確定済みの合格と不合格だけを反映し、保留や未選択の項目は変更しません。

## Optional skill / advanced automation

An assistant can use `skills/krea2-animadex-review/SKILL.md` to discover folders and call inspect/prepare directly. This uses the same comparison template and matching code as the setup screen. The existing `python app/tools/create_comparison.py` remains an advanced command-line alternative; ordinary users use START_COMPARISON.

## AnimaDex比較を使う前の準備

AnimaDexは別のアプリです。[公式サイト](https://animadex.net/)・[ローカル版と導入手順](https://github.com/zetaneko/AnimaDex)・[公式データ取り込み手順](https://github.com/zetaneko/AnimaDex/blob/main/docs/import-from-site.md)を参照してください。

1. AnimaDexの手順に従って導入・設定し、一度起動してローカルのカタログが開くことを確認します。
2. キャラクター情報と比較用の参照画像（サムネイル）をPCへ取り込みます。最初のサンプルだけでは全件の比較はできません。AnimaDexのオフラインデータ書き出し・取り込み手順で必要な画像をダウンロードし、ローカルで表示できる状態にしてください。Webサイトを開くだけではローカルへ保存されません。
3. 本カタログの `AnimaDex-Comparison` 内のSTART_COMPARISONを開き、AnimaDexの保存場所を選択します。独自のデータ保存先なら「詳細設定」でDBと画像フォルダーも選べます。

**準備後はAnimaDexを起動しておく必要はありません。** ローカルのSQLite DBを読み取り専用で参照し、画像ファイルを直接表示します。AnimaDexのWebサーバーとは通信しません。DBと画像は移動・削除せず残してください。比較の作成・再作成と判定の反映時にはKrea2カタログを起動します。作成済みの比較を見るだけなら、両アプリ本体のサーバーは停止していても使えます。

AnimaDex自体の設定が難しければ、ChatGPT・Claude・Codex等のLLMへ、公式手順を示して依頼できます。例えば「私のOSでAnimaDexを導入し、キャラクター情報とサムネイルをローカルへ取り込んで、画面で表示できるところまで案内してください」と伝え、OSと保存先を知らせます。書き出し用トークンなどの秘密情報は公開しないでください。本カタログがAnimaDexを自動インストールすることはありません。
